SQL Data Cleaning

This project was completed as part of the Alex The Analyst Data Analyst Bootcamp. 
It focuses on using SQL to clean and prepare a dataset for further analysis.

Tools Used
- SQL
- MySQL

The project covers common data-cleaning techniques, including:

- Inspecting the dataset
- Handling missing and null values
- Identifying and removing duplicate records
- Standardizing inconsistent data
- Cleaning and formatting data
- Checking data quality and consistency


Learning Outcome
Through this project, I practiced using SQL to identify common data-quality issues and prepare a dataset for analysis.
